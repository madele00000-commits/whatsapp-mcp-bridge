# WhatsApp MCP Bridge

A Hugging Face Gradio Space that runs GOWA and exposes its MCP endpoint.

Open the Space and scan the WhatsApp QR code. MCP clients can connect to `https://<space>.hf.space/mcp`.

The Space downloads the latest Linux amd64 GOWA release on startup.
